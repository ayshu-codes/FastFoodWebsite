# Fast Food Express 🍔

A clean and responsive **Online Fast Food Ordering Website** built using **HTML and CSS**.  
This project demonstrates a simple food ordering interface, menu display, and user-friendly layout suitable for restaurants or food services.

---

## 🌟 Features
- Attractive homepage with fast food images  
- Menu section displaying burgers, pizza, sandwiches, etc.  
- Online order form layout (HTML-only, non-functional backend)  
- Contact section for users  
- Fully responsive design for desktops and tablets  
- Clean, modern, and professional UI  

---

## 🛠 Technologies Used
- HTML5  
- CSS3  

> No JavaScript or backend used — purely a **frontend design project**.
